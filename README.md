# RataLottie

RataLottie is a ratatui widget that displays lottie animations in [ratatui](https://github.com/ratatui-org/ratatui).

It implements the [Widget](https://docs.rs/ratatui/latest/ratatui/widgets/trait.Widget.html) trait.

It uses the [demo-player](https://github.com/LottieFiles/dotlottie-rs/blob/main/examples/demo-player/src/main.rs) as a reference implementation.
